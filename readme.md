# Инструкция по запуску проекта Transactions

Данное руководство содержит минимальный набор шагов для сборки проекта в Docker, автоматического наполнения базы данных и создания учетной записи администратора.

## Запуск приложения

1. Откройте терминал в корневой папке проекта (где находятся файлы `Dockerfile` и `docker-compose.yml`).
2. Выполните команду для сборки образов и запуска контейнеров:

```bash
docker-compose up --build
```

При старте веб-контейнер автоматически выполнит:
* Применение миграций к базе данных PostgreSQL.
* Загрузку стартовых фикстур (`statuses.json`, `types.json`, `categories.json`, `sub_categories.json`, `transactions_data.json`) из папки `fixtures/`.
* Запуск сервера разработки.

После завершения логов приложение будет доступно по адресу: `http://localhost:8000/transactions/`
На этой странице отображается таблица со списком всех транзакций, а также доступна форма для их фильтрации по датам, статусам, категориям и подкатегориям.

## Создание учетной записи администратора

Для создания суперпользователя и получения доступа к панели управления Django выполните следующие действия:

1. Не закрывая текущий терминал с работающим Docker, откройте новое (соседнее) окно терминала в этой же папке.
2. Выполните команду внутри запущенного контейнера:

```bash
docker-compose exec web python manage.py createsuperuser
```

3. Следуйте запросам в терминале: введите имя пользователя (логин) и дважды укажите пароль (символы пароля при вводе отображаться не будут).

Панель администратора будет доступна по адресу: `http://localhost:8000/admin/`
В ней вы сможете полностью управлять всеми сущностями базы данных: создавать, редактировать и удалять статусы, категории, подкатегории и транзакции через графический интерфейс.
